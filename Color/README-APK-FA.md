# رنگین‌عمارت — راهنمای APK و انتشار در کافه‌بازار

این سند هر چیزی را که دربارهٔ فایل APK بازی باید بدانی توضیح می‌دهد.

---

## فایل نهایی

- **APK امضاشده:** `download/color-manor-1.1.1.apk`
- **شناسهٔ پکیج (Package name):** `com.milad1711.colormanor`
- **نام اپ (روی گوشی):** «عمارت رنگین»
- **نسخه:** `1.1.1` (versionCode = 3)
- **حداقل اندروید:** 5.0 (API 21) — **هدف:** Android 14 (API 34)
- **حجم:** حدود ۳.۳ مگابایت
- **مجوزها:** `INTERNET` + `com.farsitel.bazaar.permission.PAY_THROUGH_BAZAAR` (فقط برای پرداخت درون‌برنامه‌ای بازار)

### نسخهٔ ۱.۱٫۱ چه چیز جدیدی دارد؟
1. **رفع کامل ارور «Web page not available» — این بار با پیدا شدن باگ واقعی.** دو باگ پشت هم بود:
   - در نسخهٔ ۱٫۰٫۰ فایل‌های بازی بدون پوشهٔ `assets/` داخل APK بسته‌بندی شده بودند؛
   - در نسخهٔ ۱٫۱٫۰ فایل‌ها درست بسته‌بندی شده بودند اما کد جاوا هنگام خواندن فایل‌ها، پیشوند پوشهٔ `www/` را جا می‌انداخت — پس هیچ فایلی پیدا نمی‌شد و WebView به شبکه می‌افتاد و همان ارور DNS می‌داد.
   حالا هر سه درگاه بسته شده: مسیرها با پیشوند `www/` خوانده می‌شوند، صفحهٔ اصلی هرگز به شبکه نمی‌افتد (fallback داخلی)، و اگر به هر دلیلی بارگذاری خطا بخورد، اپ به‌طور خودکار بازی را مستقیم از `file:///android_asset/www/index.html` باز می‌کند — **دیگر صفحهٔ «Web page not available» در هیچ شرایطی ممکن نیست ظاهر شود.**
2. **خرید واقعی سکه‌ها از کافه‌بازار** — دکمهٔ «خرید» هر سه بستهٔ سکه حالا دیالوگ پرداخت رسمی کافه‌بازار را باز می‌کند، رسید را با کلید RSA پنل تو تأیید می‌کند و سکه‌ها را وصول می‌کند (جزئیات پایین).

### آیکون‌ها
آیکون ارسالی تو در همه‌جا استفاده شده: favicon وب، آیکون PWA، آیکون لانچر اندروید
(تطبیقی/Adaptive برای اندروید ۸+ و آیکون کلاسیک برای قدیمی‌ترها) و آیکون ۵۱۲ برای
پنل کافه‌بازار: `download/color-manor-bazaar-icon-512.png`

### چطور کار می‌کند؟
کل بازی (همهٔ ۱۱۰ مرحله، عمارت، فروشگاه، گردونهٔ شانس) **داخل APK است و بدون اینترنت
کامل کار می‌کند**. پیشرفت در حافظهٔ خود اپ ذخیره می‌شود. فقط بخش‌های آنلاین
(جدول رقابت، هدیهٔ ادمین، معرفی دوستان) به اینترنت و آدرس Vercel وصل می‌شوند.
خرید سکه از طریق برنامهٔ کافه‌بازار روی همان گوشی انجام می‌شود.

## نکتهٔ مهم: آدرس API داخل APK

APK فعلی برای بخش‌های آنلاین به این آدرس وصل می‌شود (داخل کد حک شده):

```
https://color-manor-milad1711.vercel.app
```

این یک **حدس بر اساس نام کاربری Turso تو** است. بعد از اینکه Vercel لینک واقعی را داد:

```bash
API_BASE=https://<لینک-واقعی-vercel>.vercel.app bash scripts/build-apk.sh
```

اگر آدرس غلط باشد، بازی کاملاً سالم کار می‌کند؛ فقط جدول رقابت و معرفی دوستان خالی می‌ماند
تا با آدرس درست دوباره بیلد بگیری.

## 💰 پرداخت درون‌برنامه‌ای کافه‌بازار (سکه‌ها)

طبق مستندات به‌روز بازار (کتابخانهٔ رسمی Poolakey 2.3.0)، پروتکل IAB v3 داخل خود اپ
پیاده‌سازی شده: اتصال به سرویس بازار → دیالوگ پرداخت → تأیید امضای رسید با کلید RSA
→ شمارش سکه → مصرف (consume) خرید.

### شناسهٔ محصولات — باید در پنل بازار بسازی!
قبل از انتشار، در پنل توسعه‌دهندگان بازار بخش **درون‌پرداخت → مدیریت محصولات**،
سه محصول «مصرفی» (In-App) با **دقیقاً همین شناسه‌ها** بساز:

| شناسهٔ محصول (Product ID) | تعداد سکه | قیمت پیشنهادی |
|---|---|---|
| `coin_pack_small` | 1,200 | 57,000 تومان |
| `coin_pack_medium` | 2,900 | 129,000 تومان |
| `coin_pack_golden` | 6,800 | 271,000 تومان |

⚠️ شناسه‌ها باید **کاراکتر به کاراکتر** همین باشند (حروف کوچک و زیرخط). اگر فرق کنند،
خرید انجام می‌شود ولی سکه‌ی اضافه نمی‌شود.

### کلید RSA
کلید RSA که از پنل فرستادی داخل اپ حک شده
(`android/java/com/milad1711/colormanor/MainActivity.java` — ثابت `RSA_KEY`) و
امضای هر رسید را با الگوریتم SHA1withRSA تأیید می‌کند؛ همان روش رسمی Poolakey.
اگر روزی کلید پنل را عوض کردی، فقط همین ثابت را عوض کن و دوباره بیلد بگیر.

### منطق امن سکه‌ها
- هر خرید فقط یک‌بار شمرده می‌شود (ledger توکن‌ها در حافظهٔ اپ).
- اگر وسط خرید اپ بسته شود، دفعهٔ بعد باز شدن، خرید ناتمام خودکار بازیابی و وصول می‌شود.
- خرید مصرف‌شده (consume) می‌شود تا کاربر بتواند دوباره همان بسته را بخرد.

### تست پرداخت قبل از انتشار
بازار خرید واقعی را فقط برای نسخه‌های **منتشرشده** فعال می‌کند. برای تست بدون ورود
درگاه: در پنل بازار نسخه را به‌صورت **بتا (نسخهٔ آزمایشی)** آپلود کن و خودت را به‌عنوان
آزمون‌کننده اضافه کن — خریدهای بتا واقعاً پول کم می‌کنند؛ برای آزمایشِ فرایند بهتر است
اول یک محصول ارزان‌تر موقت بسازی و بعد حذفش کنی.

## بازسازی APK (وقتی بازی را آپدیت کردی)

1. کد را تغییر بده.
2. در `android/AndroidManifest.xml` نسخه را بالا ببر:
   - `android:versionCode="4"` (هر انتشار +۱، هرگز تکراری نباشد — الان روی ۳ است)
   - `android:versionName="1.1.2"`
3. سرور dev را خاموش کن و بیلد بگیر:
   ```bash
   pkill -f "next dev"
   API_BASE=https://<لینک-vercel> bash scripts/build-apk.sh
   ```
4. APK جدید در `download/` ساخته می‌شود.

|---|---|

دارد که عمداً داخل Git قرار نمی‌گیرد.

## چک‌لیست انتشار در کافه‌بازار

1. در [پنل توسعه‌دهندگان بازار](https://developer.cafebazaar.ir) ثبت‌نام کن (مدارک هویتی لازم است).
2. «افزودن برنامهٔ جدید» → آپلود `color-manor-1.1.1.apk`.
3. مشخصات:
   - **نام:** عمارت رنگین
   - **دسته:** بازی‌ها → پازل و منطقی
   - **آیکون:** `color-manor-bazaar-icon-512.png`
   - **توضیحات کوتاه:** بازی معما و سرگرمیِ مرتب‌سازی رنگ‌ها با بازسازی عمارت — ۱۱۰ مرحله!
   - **توضیحات کامل:** ویژگی‌ها را بنویس (۱۱۰ مرحله، عمارت با ۱۶ فضا، فروشگاه ۹۴ قلم، گردونهٔ روزانه، دو زبانه، آفلاین کامل، جدول رقابت)
4. **اسکرین‌شات** (حداقل ۲ تا، پیشنهاد ۴-۸): از خود گوشی بگیر — صفحهٔ اصلی، یک مرحله، عمارت، فروشگاه.
5. دسترسی‌ها: «اینترنت» + «پرداخت از طریق کافه‌بازار» — اولی برای جدول رقابت، دومی برای خرید سکه.
6. محصولات درون‌پرداخت را (جدول بالا) قبل از ارسال ثبت کن.
7. بعد از تأیید (معمولاً ۱ تا ۳ روز)، صفحهٔ اپت فعال می‌شود.

## تست قبل از آپلود

1. APK را به گوشی اندرویدت بفرست (کابل، تلگراف ذخیره‌شده، یا گوگل‌درایو).
2. روی فایل بزن → اجازهٔ «نصب از منابع ناشناس» را بده.
3. چک کن: باز شدن بازی، چند مرحله بازی، رفتن به عمارت، چرخاندن صدا/لرزش،
   بستن و باز کردن دوباره (پیشرفت حفظ شود؟)، دکمهٔ بازگشت گوشی.
4. اگر همهٔ مراحل خوب بود → آپلود در بازار.
